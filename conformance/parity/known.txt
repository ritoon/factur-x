# Écarts connus et justifiés entre factur-x et les validateurs de référence.
#
# Une ligne par écart : référence, facture, écart, raison.
#   référence : kosit, mustang ou * (les deux)
#   facture   : origine de la facture (corpus/… ou kosit/…) ; * vaut pour
#               n'importe quelle suite de caractères, / compris
#   écart     : +RÈGLE en erreur chez factur-x seul, -RÈGLE en erreur chez la
#               référence seule ; une * finale vaut pour toutes les règles de
#               ce préfixe ; SCHEMA désigne les erreurs de schéma XSD
#   raison    : le reste de la ligne, obligatoire
#
# Un écart absent de ce fichier fait échouer le job de parité ; une ligne qui
# ne correspond plus à aucun écart est signalée dans le rapport.
